| # | 轨迹 | 特征 | 激励水平 |

| T3 | 圆形轨迹 | 恒速圆周 | 高（持续机动） |

## 2. 实验模块

### Block A: 可辨识性验证（回应 M1）

**目的**: 验证激励门控的必要性和有效性

| Exp | 方法 | 海流 | 轨迹 | 指标 |
|-----|------|------|------|------|
| A1 | DMAO-SMC | C3 (阶跃) | T1 (直航) | Vc, βc 估计是否发散 |
| A2 | DMAO-SMC | C3 (阶跃) | T3 (圆形) | Vc, βc 收敛时间 |
| A3 | EG-DMAO-SMC | C3 (阶跃) | T1 (直航) | 门控是否防止误更新 |
| A4 | EG-DMAO-SMC | C3 (阶跃) | T3 (圆形) | 机动时收敛速度 |

**假设**:
- H_A1: 直航时 DMAO 估计发散或不变（J 奇异）
- H_A2: 机动时 DMAO 在 2-5s 内收敛
- H_A3: EG-DMAO 门控正确阻止直航时的误更新
- H_A4: 机动时 EG-DMAO 响应速度与 DMAO 一致

**成功标准**: A1 不发散（不恶化）; A2 收敛时间 < 10s; A3/A4 门控正确率 > 95%

### Block B: CFD 精度灵敏度（回应 M2）

**目的**: 验证死区机制在不同 CFD 误差水平下的鲁棒性

| Exp | 方法 | CFD扰动 | 海流 | 轨迹 | 指标 |
|-----|------|---------|------|------|------|
| B1 | EGDMAO-SMC | 0%（名义） | C1 | T2 | 基线 |
| B2 | EGDMAO-SMC | ±5% 阻力系数 | C1 | T2 | Vc估计偏移 |
| B3 | EGDMAO-SMC | ±10% 阻力系数 | C1 | T2 | Vc估计偏移 |
| B4 | EGDMAO-SMC | ±20% 阻力系数 | C1 | T2 | Vc估计偏移 |
| B5 | DMAO-SMC | ±10% | C1 | T2 | 无死区对比 |
| B6 | EKF-SMC | ±10% | C1 | T2 | EKF对比 |

**假设**:
- H_B1-4: 死区内（±5%,±10%）Vc估计偏移 < 0.02 m/s
- H_B5: 无死区 DMAO 在 ±10% 时 Vc偏移 > 0.05 m/s（验证死区必要性）
- H_B6: EKF 在 ±10% 时 Vc偏移 > 0.03 m/s（验证DMAO分离优势）

**成功标准**: 死区机制在模型误差 ≤ 10% 时有效抑制海流估计偏移

### Block C: 与运动学观测器对比（回应 M3）

**目的**: 定量验证动力学观测器在机动场景中的响应速度优势

| Exp | 方法 | 海流 | 轨迹 | 指标 |
|-----|------|------|------|------|
| C1 | KIN-SMC | C3 (阶跃) | T1 (直航) | 收敛时间 |
| C2 | KIN-SMC | C3 (阶跃) | T3 (圆形) | 收敛时间 |
| C3 | EGDMAO-SMC | C3 (阶跃) | T1 | 收敛时间（不应更新） |
| C4 | EGDMAO-SMC | C3 (阶跃) | T3 | 收敛时间 |

**关键指标**: 海流阶跃后 Vc 估计恢复到真值 ±10% 的时间

**假设**:
- H_C1: KIN 收敛时间 10-30s（需要位置误差累积）
- H_C4: EG-DMAO 收敛时间 2-5s（利用加速度残差）
- **定量优势**: EG-DMAO 比 KIN 快 3-10× 在机动场景中

**成功标准**: C4 收敛时间 < C2 收敛时间 × 0.5

### Block D: 全面对比实验（核心）

**目的**: 7种方法 × 5种海流 × 3种轨迹的完整对比

| 指标 | 定义 | 单位 |
|------|------|------|
| **海流估计精度** | | |
| RMSE_Vc | \(\sqrt{\frac{1}{N}\sum(\hat{V}_c - V_c^{true})^2}\) | m/s |
| RMSE_beta | \(\sqrt{\frac{1}{N}\sum(\hat{\beta}_c - \beta_c^{true})^2}\) | rad |
| MAE_Vc | \(\frac{1}{N}\sum|\hat{V}_c - V_c^{true}|\) | m/s |
| **控制性能** | | |
| RMSE_psi | 航向误差 RMSE | rad |
| RMSE_xy | 横向轨迹误差 RMSE | m |
| RMSE_z | 深度误差 RMSE | m |
| **控制品质** | | |
| RMS_tau | 控制力/力矩 RMS | N / Nm |
| RMS_delta | 等效舵角 RMS | rad |
| **观测器特性** | | |
| T_conv | 海流估计收敛时间 | s |
| Conf_valid | 置信度与估计误差的相关性 | — |

**矩阵**: 7方法 × 5海流 × 3轨迹 = **105 组实验**

**优先运行**: 7方法 × 3海流(C1,C2,C3) × 2轨迹(T1,T3) = **42 组核心实验**

### Block E: 消融实验

**目的**: 验证 EG-DMAO 各组件贡献

| Exp | 配置 | 移除的组件 |
|-----|------|-----------|
| E1 | 完整 EG-DMAO | —（基线） |
| E2 | EG-DMAO - 门控 | 激励门控 |
| E3 | EG-DMAO - 死区 | 死区自适应律 |
| E4 | EG-DMAO - 双模型 | 名义模型（仅用观测器模型） |
| E5 | EG-DMAO - GM | GM 时间先验（随机游走替代） |
| E6 | EG-DMAO - 融合 | 互补滤波（仅动力学输出） |

**场景**: C2 (GM缓变流) × T2 (正弦转向)

**假设**:
- H_E2: 移除门控 → 直航段估计抖动增加
- H_E3: 移除死区 → 模型误差导致估计偏置
- H_E4: 移除双模型 → 收敛速度下降
- H_E5: 移除GM → DVL短暂失效时估计快速发散
- H_E6: 移除融合 → 稳态精度下降

### Block F: DVL 失效鲁棒性

**目的**: 验证 GM 时间先验在传感器失效时的作用

| Exp | 配置 | DVL失效时段 | 指标 |
|-----|------|------------|------|
| F1 | EGDMAO-SMC | t=80-100s (20s) | Vc估计漂移 |
| F2 | DMAO-SMC | t=80-100s | Vc估计漂移 |
| F3 | EKF-SMC | t=80-100s | Vc估计漂移 |

**成功标准**: F1 漂移 < F2 漂移（GM 优势验证）

## 6. 风险与缓解

| 风险 | 概率 | 缓解措施 |
|------|:---:|---------|
| 死区阈值难以标定 | 中 | Block B 中做参数扫描确定最优值 |
| 激励门控阈值选择困难 | 低 | 基于 XHY 典型机动参数离线计算 |
| EKF 基线性能意外好 | 低 | 准备多组 EKF 调参（Q矩阵扫描） |
| DMAO 在高噪声下发散 | 中 | 备选方案：降低自适应增益 + 增加低通滤波 |
