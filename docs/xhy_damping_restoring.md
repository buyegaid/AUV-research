# XHY AUV 阻尼力与恢复力矩阵

## 概述

XHY 6-DOF 动力学模型中的非保守力包括两类：

```
M * nu_dot_r + C * nu_r + D * nu_r + g = tau
```

- **阻尼力** `D * nu_r`：来自 CFD 数据的平动阻力 + 时间常数法转动阻尼
- **恢复力** `g`：重力与浮力的合力/力矩向量

两者均在 `model/xhy.m` 第 80-84 行构造。

---

## 1. 阻尼力

### 计算入口

```matlab
% model/xhy.m:80
[tau_drag, D] = xhy_drag_cfd(nu_r, M);
```

函数 `xhy_drag_cfd`（`model/xhy_drag_cfd.m`）返回两个量：
- `tau_drag`：6×1 阻尼力/力矩向量（直接作用于 tau_out 中）
- `D`：6×6 阻尼矩阵（速度相关，对角阵）

### 1.1 平动阻力（CFD 拟合）

对三个平动自由度分别进行 CFD 仿真，拟合得到二次+线性阻力模型（强制过原点）：

| 自由度 | CFD坐标系 | 拟合公式 (R²) | 速度范围 |
|--------|----------|---------------|----------|
| 纵荡 (surge) | CFD Z（前） | `Fz_cfd = 3.77·w² + 0.76·w` (R²=1.000) | 0.25–1.5 m/s |
| 横荡 (sway) | CFD X（右） | `Fx_cfd = 142.85·u² − 10.57·u` (R²=0.999) | 0.2–1.0 m/s |
| 垂荡 (heave) | CFD Y（上） | `Fy_cfd = 45.04·v² + 1.45·v` (R²=0.999) | 0.2–1.0 m/s |

**CFD 坐标系不同于动力学坐标系**，需要做转换：

```
CFD(右上前) → 动力学(前右下/NED)
动力学 X_前 ← CFD Z_前
动力学 Y_右 ← CFD X_右
动力学 Z_下 ← -CFD Y_上
```

转换后的系数（`model/xhy_drag_cfd.m:34-36`）：

```
纵荡 (X): d1 = 0.76,    d2 = 3.77
横荡 (Y): d1 = -10.57,  d2 = 142.85
垂荡 (Z): d1 = 1.45,    d2 = 45.04
```

**平动阻力公式**（第40-42行）：

```
Fx = -(d1_x · u + d2_x · u · |u|)
Fy = -(d1_y · v + d2_y · v · |v|)
Fz = -(d1_z · w + d2_z · w · |w|)
```

负号表示阻力方向与运动方向相反。代入数值：

```
Fx = -(0.76·u  + 3.77·u·|u|)
Fy = -(-10.57·v + 142.85·v·|v|)
Fz = -(1.45·w  + 45.04·w·|w|)
```

**关键观察**：横荡方向（Y）的线性项系数为负（`-10.57`），意味着在极低速度下线性项为主导，且符号反转——这在物理上表示极低速时存在小范围的不稳定或 CFD 拟合在极低雷诺数下的外推误差。

### 1.2 转动阻尼（时间常数法）

转动阻尼采用时间常数/阻尼比方法（第45-57行），而非 CFD 数据：

```matlab
zeta4 = 0.3;    % 横滚阻尼比
zeta5 = 0.8;    % 俯仰阻尼比
T6 = 1;          % 艏摇时间常数 (s)
```

**等效自然频率**（由静稳性力臂推导）：

```
W = 33 * 9.81 = 323.73 N           % 重量
r_bG_z = 0                         % CG 垂向位置
r_bB_z = -0.03                     % CB 垂向位置
omega_4 = sqrt(W*(r_bG_z - r_bB_z) / M(4,4))   % 横滚自然频率
omega_5 = sqrt(W*(r_bG_z - r_bB_z) / M(5,5))   % 俯仰自然频率
```

其中 `M(4,4) = Ix + K_pdot = 0.5408 + 0.006 = 0.5468`，`M(5,5) = Iy + M_qdot = 2.1075 + 0.043 = 2.1505`：

```
omega_4 = sqrt(323.73 * 0.03 / 0.5468) = sqrt(17.77) = 4.22 rad/s
omega_5 = sqrt(323.73 * 0.03 / 2.1505) = sqrt(4.52)  = 2.13 rad/s
```

**转动阻尼力矩**：

```
K   = -M(4,4) * 2 * zeta4 * omega_4 * p   横滚阻尼
My  = -M(5,5) * 2 * zeta5 * omega_5 * q   俯仰阻尼
Nz  = -M(6,6) / T6 * r                    艏摇阻尼
```

代入数值：

```
K   = -0.5468 * 2 * 0.3 * 4.22 * p  = -1.384 * p
My  = -2.1505 * 2 * 0.8 * 2.13 * q  = -7.330 * q
Nz  = -(1.849 + 0.138) / 1 * r       = -1.987 * r
```

### 1.3 总阻尼矩阵 D

D 为 6×6 对角矩阵，对角线元素即各自由度速度系数的绝对值（第62-69行）：

```
D = diag([
    |0.76  + 3.77·|u||      % D(1,1): 纵荡
    |-10.57 + 142.85·|v||    % D(2,2): 横荡
    |1.45  + 45.04·|w||     % D(3,3): 垂荡
    1.384                    % D(4,4): 横滚 (线性)
    7.330                    % D(5,5): 俯仰 (线性)
    1.987                    % D(6,6): 艏摇 (线性)
])
```

平动阻尼依赖于瞬时速度（二次阻力），转动阻尼为常数线性阻尼。在状态方程中 `D * nu_r` 给出阻尼力向量。

### 1.4 阻力向量 tau_drag

`tau_drag` 直接以向量形式构造（第59行），结构等价于 `-D * nu_r`：

```
tau_drag = [Fx; Fy; Fz; K; My; Nz]
```

在 `xhy.m:122` 中与推进器推力叠加：

```
tau_out = tau + tau_drag;   % tau 来自推进器，tau_drag 为负（阻力）
```

## 2. 恢复力（重力与浮力）

### 构造方法

```matlab
% model/xhy.m:76-77, 83-84
g_mu = gravity(mu);         % 当地重力加速度
W = m * g_mu;               % 重量 (N)
B = W * 1.01;               % 浮力 (N)，略大于重量
r_bG = [0, 0, 0]';          % 重心在 CO 处
r_bB = [0, 0, -0.03]';      % 浮心在 CO 下方 3cm
[R, ~] = eulerang(phi, theta, psi);  % 旋转矩阵
g = gRvect(W, B, R, r_bG, r_bB);     % 6×1 恢复力向量
```

`gRvect` 来自 MSS 工具箱（`Lib/gRvect.m`）。

### 物理参数

```
m        = 33       kg         质量
g_mu     = ~9.81    m/s²       重力加速度（纬度 63.45°）
W        = ~323.7   N          重量
B        = ~327.0   N          浮力（正浮力 1%）
W − B    = −3.24    N          净浮力（向上）
```

CG 与 CO 重合，CB 在 CO 下方 3cm。这是一个**静稳定配置**：浮心在重心下方，产生扶正力矩。

### gRvect 公式

`gRvect(W,B,R,r_bg,r_bb)` 的实现（`Lib/gRvect.m:27-33`）：

```
R = Rz(ψ) · Ry(θ) · Rx(φ)   （机体系 → NED 系旋转矩阵）

g(1:3) = −(W−B) * [R(3,1); R(3,2); R(3,3)]           ← 合力

g(4:6) = −(r_bg×W − r_bb×B) 在机体系的分量              ← 合力矩
```

其中 `R(3,:)` 是旋转矩阵第三行（NED Z 轴在机体系的分量）：

```
R(3,1) = −sin θ
R(3,2) =  cos θ sin φ
R(3,3) =  cos θ cos φ
```

### 2.1 恢复力（平动分量）

```
g(1) =  (W−B) sin θ          纵荡恢复力
g(2) = −(W−B) cos θ sin φ    横荡恢复力
g(3) = −(W−B) cos θ cos φ    垂荡恢复力
```

**物理含义**：当 AUV 有俯仰角 θ > 0（抬头）时，重力沿船体纵轴的分量指向后方，浮力分量指向前方。由
于 B > W，浮力分量更大，`g(1) = (W−B) sinθ` 为负（W−B < 0），产生向前的恢复力将 AUV 推向前进方
向——即抬头时 AUV 有抬头前进的趋势，符合正浮力 AUV 的物理行为。

### 2.2 恢复力矩（转动分量）

将 `r_bG = [0,0,0]`、`r_bB = [0,0,−0.03]` 代入：

```
g(4) =  0.03 * B * cos θ sin φ       横滚恢复力矩
g(5) = −0.03 * B * sin θ             俯仰恢复力矩
g(6) =  0                             艏摇力矩恒为零
```

**物理含义**：

- **横滚**：φ > 0（右倾）时 `g(4) > 0`，产生正向横滚力矩——因为浮心在重心之下，右侧时浮力相对重心产
  生向右的力矩，倾向于进一步倾斜。这是 CB 在 CG 之下的预期行为（扶正力矩由推进器和控制器提供）。

- **俯仰**：θ > 0（抬头）时 `g(5) < 0`，产生低头力矩（负俯仰力矩）。这是因为浮心在 CO 之下、后方，
  抬头时浮力产生逆时针力矩试图让鼻部回正。

- **艏摇**：`g(6) = 0`，因为 `r_bG = r_bB = [0,0,0]` 在 xy 平面的投影重合，无力臂。

### 2.3 恢复力与推进器的关系

由于 B > W（正浮力 1%），AUV 在无控制时会缓慢上浮。垂向推进器（vert1、vert2）需要持续输出小推力来维持深度。这种设计使 AUV 在推进器全部失效时自动浮出水面，是一种安全设计。

净浮力：`B − W = 323.7 * 0.01 ≈ 3.24 N`，仅占总重量的 1%，对深度控制的扰动很小。

## 3. 总外力在状态方程中的作用

在 `model/xhy.m:125` 中：

```
xdot(1:6) = Dnu_c + M \ (tau_out - C * nu_r - g)
```

其中 `tau_out = tau + tau_drag`（推进器推力 + CFD 阻力）。因此实际的有效外力是：

```
tau_effective = tau (推进器) + tau_drag (阻力) - C*nu_r (科氏力) - g (恢复力)
```

`D * nu_r` 并不显式出现在方程中——`tau_drag` 已经以向量形式包含了阻尼效应。D 矩阵的输出单独保
存为返回值，供控制器（`smc_6dof`）作为前馈项使用。
