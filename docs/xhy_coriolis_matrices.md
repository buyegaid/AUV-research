# XHY AUV 科里奥利矩阵

## 概述

XHY 的 6-DOF 动力学模型中，总科里奥利矩阵由两部分组成：

```
C = CRB + CA
```

- **CRB**：刚体科里奥利-向心矩阵（Rigid-body Coriolis-centripetal matrix）
- **CA**：附加质量科里奥利-向心矩阵（Added-mass Coriolis-centripetal matrix）

两者均在 `model/xhy.m` 第 66-73 行构造，总惯性矩阵 `M = MRB + MA` 在第 74 行。

在状态方程（第125行）中使用：

```
xdot = [ Dnu_c + M \ (tau_out - C * nu_r - g)
         J * nu ]
```

在控制器 `controller/xhy/smc_6dof.m` 中以力向量形式 `C_nu = C * nu_r` 作为前馈项（第66行）：

```
tau_cmd = M * nu_cmd_ddot + C_nu + D_nu + g_vec + tau_eso
```

## 1. 刚体科里奥利矩阵 CRB

### 构造方法

由于 CG = CO，无需平移轴变换，直接在 CG 下构造：

```matlab
nu_2 = nu(4:6);        % [p, q, r]'
CRB = [ m * Smtrx(nu_2)    O3
        O3               -Smtrx(Ig*nu_2) ];
```

使用 MSS 工具箱 `Smtrx` 函数生成反对称矩阵。`Smtrx(a)` 返回 3×3 反对称矩阵 S(a)，使得 `S(a)·b = a × b`。

### 解析形式

```
S(nu_2) = [ 0  -r   q ]
          [ r   0  -p ]
          [-q   p   0 ]

CRB = [ m·S(nu_2)         0₃     ]
      [ 0₃           -S(Ig·nu_2) ]
```

### 展开形式

```
CRB = [ 0    -m·r   m·q     0      0      0   ]
      [ m·r   0    -m·p     0      0      0   ]
      [-m·q  m·p    0       0      0      0   ]
      [ 0     0     0       0    Iz·r  -Iy·q ]
      [ 0     0     0    -Iz·r    0    Ix·p  ]
      [ 0     0     0     Iy·q  -Ix·p   0    ]
```

### 数值形式（代入参数）

```
CRB = [ 0       -33r       33q       0         0          0      ]
      [ 33r      0        -33p       0         0          0      ]
      [-33q     33p        0         0         0          0      ]
      [ 0        0         0         0      1.849r    -2.107q   ]
      [ 0        0         0      -1.849r      0       0.541p   ]
      [ 0        0         0       2.107q   -0.541p      0      ]
```

### 物理含义

- **左上 3×3 块**（`m·S(nu_2)`）：线速度方向的科里奥利力，来自角速度对线速度的旋转效应
- **右下 3×3 块**（`-S(Ig·nu_2)`）：陀螺力矩，来自角速度分量之间的耦合

CRB 只依赖于角速度 `[p, q, r]`，与线速度无关——这是 Fossen 2021 的"线速度独立表示"。

## 2. 附加质量科里奥利矩阵 CA

### 构造方法

两步构造：

**Step 1**（第68行）：调用 MSS 工具箱 `m2c(MA, nu_r)` 生成标准形式的 CA。

```matlab
CA = m2c(MA, nu_r);
```

对于对角附加质量矩阵 `MA = diag[Xu_dot, Yv_dot, Zw_dot, Kp_dot, Mq_dot, Nr_dot]`，
`m2c` 产生（Fossen 2021, Eq. 6.43）：

```
CA(nu_r) = [ 0        0        0        0        -Zw·w_r     Yv·v_r ]
          [ 0        0        0       Zw·w_r      0        -Xu·u_r ]
          [ 0        0        0      -Yv·v_r     Xu·u_r      0     ]
          [ 0      -Zw·w_r   Yv·v_r     0        -Nr·r_r    Mq·q_r ]
          [ Zw·w_r    0    -Xu·u_r    Nr·r_r       0       -Kp·p_r ]
          [-Yv·v_r  Xu·u_r    0      -Mq·q_r     Kp·p_r      0     ]
```

代入数值后：

```
CA(nu_r) = [ 0       0        0        0      -47.10w_r   132.11v_r ]
          [ 0       0        0      47.10w_r     0       -11.28u_r ]
          [ 0       0        0    -132.11v_r   11.28u_r      0      ]
          [ 0    -47.10w_r 132.11v_r    0      -0.138r_r   0.043q_r ]
          [47.10w_r   0   -11.28u_r  0.138r_r      0      -0.006p_r ]
          [-132.11v_r 11.28u_r  0  -0.043q_r   0.006p_r      0      ]
```

**Step 2**（第69-72行）：将不稳定的 Munk 力矩项置零。

```matlab
CA(5,3) = 0; CA(3,5) = 0;  % Munk 力矩: 俯仰 ← 垂荡
CA(5,1) = 0; CA(1,5) = 0;  % Munk 力矩: 俯仰 ← 纵荡
CA(6,1) = 0; CA(1,6) = 0;  % Munk 力矩: 艏摇 ← 纵荡
```

### 零化后的最终 CA

```
CA(nu_r) = [ 0       0        0        0        0       132.11v_r ]
          [ 0       0        0      47.10w_r    0          0      ]
          [ 0       0        0    -132.11v_r    0          0      ]
          [ 0    -47.10w_r 132.11v_r    0    -0.138r_r   0.043q_r ]
          [ 0       0        0      0.138r_r     0      -0.006p_r ]
          [ 0     11.28u_r    0    -0.043q_r  0.006p_r      0      ]
```

### 为什么要置零？

Munk 力矩来自势流理论推导。在真实粘性流体中，旋转运动产生的二次阻尼会抵消这些力矩。当 CFD 阻尼模型中缺少精确的旋转阻尼项时，Munk 力矩会导致模型不稳定。采用保守策略：直接置零，用控制器的鲁棒性来覆盖未建模动态。

### 与 REMUS 的区别

REMUS 模型（`model/remus100.m`）额外置零了一对项：

```matlab
CA(6,2) = 0; CA(2,6) = 0;  % XHY 未置零此项
```

XHY 保留了横荡-艏摇耦合项（`X_udot·u_r`），即 CA(6,2) 和 CA(2,6)。

---

## 3. 总科里奥利矩阵 C = CRB + CA

```
C(nu_r) = CRB(p,q,r) + CA(u_r,v_r,w_r,p_r,q_r,r_r)
```

- CRB 只依赖角速度 `[p, q, r]`（流体无关，纯刚体力学）
- CA 依赖全部六个自由度的相对速度 `nu_r`（流体附加质量效应）
- CRB + CA 一起构成完整的科里奥利力
