## 附录A: Fluent转动阻尼CFD仿真方案

### A.1 目标

通过CFD仿真获取XHY AUV在纯旋转运动下的阻尼力矩:
- 横滚阻尼 K(p): 力矩 vs 角速度p
- 俯仰阻尼 M(q): 力矩 vs 角速度q
- 偏航阻尼 N(r): 力矩 vs 角速度r

### A.2 仿真策略: 旋转参考系法 (MRF/SRF)

使用**多重参考系(MRF)**或**滑移网格(SMM)**模拟AUV绕指定轴等速旋转，测量稳定后的力矩。

**原理**: 在旋转参考系中，AUV视为静止，流体以离心力和科氏力形式响应，可直接提取作用于AUV的力矩。

### A.3 仿真工况矩阵

```
轴      角速度范围         取点数   参考系旋转轴
─────────────────────────────────────────────
横滚p   ±0.5, ±1.0, ±2.0  rad/s   6个   绕体轴X
─────────────────────────────────────────────
俯仰q   ±0.5, ±1.0, ±2.0  rad/s   6个   绕体轴Y
─────────────────────────────────────────────
偏航r   ±0.5, ±1.0, ±2.0  rad/s   6个   绕体轴Z
─────────────────────────────────────────────
总计: 18个仿真工况
```

- 正角速度: 按右手定则绕轴正方向旋转
- 负角速度: 反方向旋转（验证对称性）
- 来流速度: **V=0**（纯旋转，无平动来流）
- 如果MRF不支持纯旋转无来流，设置极小来流 V=0.01 m/s

### A.4 Fluent设置

```
求解器:      稳态 (Steady), 压力基 (Pressure-Based)
湍流模型:    k-ω SST (与平动CFD保持一致)
参考系:      MRF (Moving Reference Frame)
旋转速度:    按工况表设置在对应旋转轴上
远场边界:    速度入口(V=0) + 压力出口
壁面:        无滑移壁面 (No-slip wall)
参考值:      AUV长度≈1m, 参考面积=迎流截面积
收敛判断:    残差<1e-5 且 力矩监测稳定
```

### A.5 求解量

每次仿真提取:
- **力矩向量**: `[Mx, My, Mz]` (N·m)，在体坐标系下
- 主力矩（对应旋转轴）用于拟合
- 耦合力矩（非旋转轴）用于评估交叉耦合

### A.6 数据处理

对每个旋转轴，拟合阻尼力矩公式:

```
纯旋转阻尼模型: M_damp = -K_linear * omega - K_quad * |omega| * omega

数据拟合:
  提取力矩M(omega)（符号: 阻尼力矩与角速度反向）
  拟合 M = a*omega + b*|omega|*omega
  阻尼系数: d_linear = -a, d_quad = -b (均为正数)
```

在AUV动力学方程中对应的阻尼项:
```
K_damp = -(d44 + d44q*|p|) * p    [横滚]
M_damp = -(d55 + d55q*|q|) * q    [俯仰]
N_damp = -(d66 + d66q*|r|) * r    [偏航]
```

### A.7 脚本化执行流程

建议在另一个项目中编写Python脚本驱动Fluent:

```
脚本工作流:
1. 读取XHY.IGS几何模型
2. 网格划分 (自动meshing, 记录网格数)
3. 循环18个工况:
   a. 设置MRF旋转轴和速度
   b. 运行求解至收敛
   c. 提取力矩数据
   d. 保存.cas和.dat
4. 汇总所有工况力矩
5. 最小二乘拟合 d_linear, d_quad
6. 输出拟合报告 (R², 残差图)
```

### A.8 输出交付物

```
1. 18个工况的力矩原始数据 (CSV)
2. 拟合参数:
   - Roll:  d44 (线性), d44q (二次), R²
   - Pitch: d55 (线性), d55q (二次), R²
   - Yaw:   d66 (线性), d66q (二次), R²
3. 力矩vs角速度拟合图
4. Fluent .cas/.dat 存档
```

### A.9 替代方案: 旋转坐标系稳态法

如果MRF方法有收敛问题，可使用**纯旋转运动瞬态法**:
- 使用动网格+刚体运动(6DOF)
- 设定AUV绕指定轴恒速旋转
- 运行足够时间至力矩稳定
- 缺点: 计算量大（每个工况需瞬态求解）

### B.4 数据采集与处理

**每个工况记录**:
```
时间戳 | 转速n (RPM) | 推力T (N) | 扭矩Q (N·m) | 来流V (m/s)
```

**数据处理**:
```
1. 取每段稳态数据 (后20s, 剔除启动瞬态)

5. 对比正反转KT差异
```

5. 推进器效率: η = (KT/KQ) * (J/2π)

## 附录C: 交叉耦合项辨识方法与推导 (P3)

### C.1 目标

| 类别 | 参数 | 物理意义 |
|------|------|---------|
| 附加质量交叉项 | X_w_dot, Z_u_dot | 垂荡→纵荡耦合 |
| | Y_r_dot, N_v_dot | 偏航→横荡耦合 (Munk力矩) |
| | Z_q_dot, M_w_dot | 俯仰→垂荡耦合 |
| 阻尼交叉项 | Y_v_r, N_r_v | 横荡-偏航耦合阻尼 |
| | Z_w_q, M_q_w | 垂荡-俯仰耦合阻尼 |
| | Y_|r|v, N_|v|r | 非线性交叉阻尼 |

### C.2 附加质量交叉项: 势流理论推导

#### C.2.1 理论基础

理想流体中，AUV的附加质量张量为6×6对称矩阵:

```
MA = [Xu_dot  Xv_dot  Xw_dot  Xp_dot  Xq_dot  Xr_dot ]
     [Yv_dot  Yv_dot  Yw_dot  Yp_dot  Yq_dot  Yr_dot ]
     [Zw_dot  Zw_dot  Zw_dot  Zp_dot  Zq_dot  Zr_dot ]
     [Kp_dot  Kp_dot  Kp_dot  Kp_dot  Kq_dot  Kr_dot ]
     [Mq_dot  Mq_dot  Mq_dot  Mq_dot  Mq_dot  Mr_dot ]
     [Nr_dot  Nr_dot  Nr_dot  Nr_dot  Nr_dot  Nr_dot ]
```

对于XHY（xz平面对称，左右对称），对称性约束使得:
- xz平面对称 → MA(1,2)=MA(1,4)=MA(1,6)=MA(2,3)=MA(2,5)=MA(3,4)=MA(3,6)=MA(4,5)=MA(4,6)=MA(5,6)=0
- 保留的非零交叉项: **X_w_dot=Z_u_dot, Y_r_dot=N_v_dot, Z_q_dot=M_w_dot**

#### C.2.2 细长体理论 (Strip Theory) 估算

将AUV沿x轴离散为N个截面，每个截面的2D附加质量积分:

```
截面i的2D附加质量 (对横截面在y-z平面的椭圆近似):
  m22_i(x) = ρπ * b(x)²          [横荡方向2D附加质量]
  m33_i(x) = ρπ * c(x)²          [垂荡方向2D附加质量]
  m44_i(x) = 0                   [横滚2D附加质量≈0]

其中 b(x)=截面半宽, c(x)=截面半高

3D附加质量交叉项 (细长体积分):
  Y_r_dot = N_v_dot = ∫ x * m22_i(x) dx    [从x_min到x_max]
  Z_q_dot = M_w_dot = -∫ x * m33_i(x) dx   [从x_min到x_max]
```

**执行步骤**:
1. 从CAD模型提取XHY截面轮廓 (切片间距: 5mm)
2. 对每个截面的y-z轮廓做椭圆拟合 → b(x), c(x)
3. 数值积分求 Y_r_dot, Z_q_dot
4. 与CFD结果对比验证

#### C.2.3 CFD方法: 纯运动仿真

**方法1: 纯横荡 (测Y_r_dot, N_v_dot)**

```
设置:
  V∞=0, AUV做纯横荡运动: y(t)=y0*sin(ωt), ẏ(t)=y0*ω*cos(ωt)
  其他自由度固定 (u=w=p=q=r=0)

运动学约束:
  流体作用力: Y = -Yv_dot*ÿ - Y_r_dot*ṙ  (无r不产生ṙ项)
  实际上纯横荡只产生Y力...
```

**方法2: 纯偏航振荡 (测N_r_dot, Y_r_dot)**

```
设置:
  U=常数 (如0.5 m/s), 叠加纯偏航振荡: ψ(t)=ψ0*sin(ωt)
  r(t)=ψ0*ω*cos(ωt), ṙ(t)=-ψ0*ω²*sin(ωt)

动力学关系:
  Y(t) = Y_v_dot*v_dot + Y_r_dot*ṙ + ...
  在U≠0时, v_dot = -U*r + ... (侧滑角变化)

数据处理:
  提取Y(t)和N(t)的傅里叶分量
  与r(t)和ṙ(t)同相的分量 → 阻尼项
  与ṙ(t)同相的分量 → 附加质量项 Y_r_dot, N_r_dot
```

**推荐CFD方法**: 使用动网格+正弦振荡运动 (SMM)，频率扫频 0.5, 1.0, 2.0 rad/s

### C.3 交叉阻尼辨识: 旋转臂法 (Rotating Arm)

#### C.3.1 原理

AUV在圆形轨迹上做定常回转，侧滑角β和角速度r同时存在，可分离Y_v_r和N_r_v:

```
定常回转运动 (ṙ=0, v_dot=0):
  v = -U*sin(β)              [侧滑速度，β为漂角]
  r = U/R                     [回转角速度]

作用在AUV上的横荡力和偏航力矩:
  Y = Y_v*v + Y_r*r + Y_v|v|*v*|v| + Y_v_r*v*r + Y_r|r|*r*|r| + ...
  N = N_v*v + N_r*r + N_v|v|*v*|v| + N_v_r*v*r + N_r|r|*r*|r| + ...

通过设计不同的(R, β)组合，可解耦Y_v_r和N_v_r
```

#### C.3.2 CFD仿真工况设计

```
R (回转半径)    β (漂角)    等价v (m/s)    等价r (rad/s)
──────────────────────────────────────────────────────
5m             0°            0              U/5
5m             5°            U*sin(5°)      U/5
5m             10°           U*sin(10°)     U/5
10m            0°            0              U/10
10m            5°            U*sin(5°)      U/10
10m            10°           U*sin(10°)     U/10
20m            0°            0              U/20
20m            5°            U*sin(5°)      U/20
20m            10°           U*sin(10°)     U/20
──────────────────────────────────────────────────────
来流速度 U=0.5, 1.0 m/s → 总计 18×2=36个仿真
```

使用MRF方法，旋转域半径=R，旋转速度=r。

#### C.3.3 数据处理: 最小二乘辨识

对每个数据集(U, R, β)，已知v和r，测量Y_measured和N_measured。构造超定方程组:

```
[Y_1]     [v₁   r₁   v₁|v₁|   v₁r₁   r₁|r₁|]   [Y_v ]
[Y_2]  =  [v₂   r₂   v₂|v₂|   v₂r₂   r₂|r₂|] × [Y_r ]
[...]     [.........................]            [Y_v|v|]
[Y_n]     [vₙ   rₙ   vₙ|vₙ|   vₙrₙ   rₙ|rₙ|]   [Y_v_r]
                                                   [Y_r|r|]

Ax = b → x = pinv(A)*b

x = [Y_v, Y_r, Y_v|v|, Y_v_r, Y_r|r|]' 即为横荡阻尼系数向量
N通道同理, 得到 [N_v, N_r, N_v|v|, N_v_r, N_r|r|]'
```

**注意**: 纯旋转和纯平动工况应覆盖参数范围的对角线和非对角线区域，确保辨识可观测。

### C.4 垂荡-俯仰交叉项

对于Z_w_q和M_q_w，采用与横荡-偏航类似的方法，但运动在xz平面内:

```
工况: 不同R和攻角α的组合
  w = U*sin(α)               [垂荡速度]
  q = U/R                     [俯仰角速度]

辨识: Z_w_q, M_q_w, Z_w|w|, Z_w_q, ...
```

### C.5 输出交付物

```
1. 细长体理论估算的交叉附加质量 (Y_r_dot, Z_q_dot)
2. 旋转臂CFD仿真原始数据 (36个工况)
3. 最小二乘辨识的完整阻尼系数矩阵 (含交叉项)
4. 交叉项显著性分析 (对比忽略交叉项的误差)
5. 更新后的完整D(v)矩阵
```

## 附录D: 系统级辨识与模型验证方法 (P4)

### D.1 目标

通过自由航行试验数据，系统性地辨识和验证XHY AUV全动力学模型参数。

### D.2 方法概述

采用**时域系统辨识**策略，基于自由航行试验的输入-输出数据，使用最优估计方法辨识模型参数。

```
输入: 推进器指令序列 (已知)
输出: AUV状态轨迹 (测量)
模型: 6-DOF动力学参数
目标: min ||测量输出 - 模型输出||²
```

### D.3 辨识框架: 输出误差法 (Output Error Method)

#### D.3.1 问题建模

AUV动力学:
```
ẋ = f(x, u; θ)
y = h(x) + ν    (测量方程)
```

其中:
- x: 12维状态向量 [u v w p q r x y z φ θ ψ]
- u: 5维控制输入 [n_main n_v1 n_v2 n_s1 n_s2]
- θ: 待辨识参数向量
- y: 测量输出 (通过传感器获得)
- ν: 测量噪声

#### D.3.2 最大似然估计 (MLE)

在测量噪声为高斯白噪声假设下:

```
θ* = argmin Σ [y(t_k) - ŷ(t_k, θ)]ᵀ R⁻¹ [y(t_k) - ŷ(t_k, θ)]
      θ    k

其中:
  ŷ(t_k, θ): 给定θ下模型的预测输出
  R: 测量噪声协方差矩阵 (可同时估计)
```

#### D.3.3 梯度计算: 灵敏度方程

对于Gauss-Newton优化，需要输出对参数的梯度 ∂ŷ/∂θ:

```
灵敏度状态: S_x = ∂x/∂θ  (12×np矩阵, np=参数个数)

灵敏度方程 (对ODE求参数导数):
  dS_x/dt = (∂f/∂x) * S_x + ∂f/∂θ

  初始条件: S_x(0) = 0 (初始状态与参数无关)

输出灵敏度:
  S_y = (∂h/∂x) * S_x
```

**Jacobian计算**: ∂f/∂x 和 ∂f/∂θ 可通过解析推导或自动微分获得。AUV动力学方程结构清晰，推荐解析推导以提高效率。

#### D.3.4 参数可辨识性分析

在辨识前需分析参数的可辨识性:

**方法1: 灵敏度矩阵奇异值分析**
```
构造灵敏度矩阵: S = [S_y(t₁); S_y(t₂); ...; S_y(t_N)]  (n_meas×n_params)

做SVD: S = UΣVᵀ
检查奇异值Σ: 接近零的奇异值对应的参数方向不可辨识

条件数: κ = σ_max / σ_min → 过大表示辨识问题病态
```

**方法2: Cramér-Rao下界**
```
Fisher信息矩阵: F = Σ S_y(t_k)ᵀ R⁻¹ S_y(t_k)
参数估计协方差: cov(θ̂) ≥ F⁻¹

参数i的标准差下界: σ_i ≥ sqrt([F⁻¹]_ii)
```

### D.4 试验设计: 最优激励信号

#### D.4.1 激励设计原则

参数辨识需要输入信号充分激励系统的所有模态:

| 自由度 | 推荐激励信号 | 辨识的参数 |
|--------|-------------|-----------|
| Surge | 多级阶跃序列 (0→500→1000→2000→500 RPM) | Xu_dot, 纵荡阻尼系数 |
| Sway + Yaw | 侧推多级阶跃 + 方向反转 | Yv_dot, Y_r_dot, N_v_dot, Nr_dot, 交叉阻尼 |
| Heave + Pitch | 垂推多级阶跃 + 方向反转 | Zw_dot, Z_q_dot, M_w_dot, Mq_dot, 交叉阻尼 |

#### D.4.2 具体试验序列

```
试验1: 纵荡辨识 (纯surge)
  - 主推阶跃: [0, 500, 1000, 1500, 2000, 2500, 1500, 500, 0] RPM
  - 每段持续时间: 15s (确保稳态)
  - 采样率: 20Hz
  - 重复3次

试验2: 偏航辨识 (纯yaw + sway)
  - 侧推反向阶跃: [0, ±500, ±1000, ±1500, ±500, 0] RPM
  - 序列: 正偏航→回正→负偏航→回正
  - 每段持续时间: 20s
  - 重复3次

试验3: 俯仰辨识 (纯pitch + heave)
  - 垂推反向阶跃: [0, ±500, ±1000, ±1500, ±500, 0] RPM
  - 序列: 正俯仰→回正→负俯仰→回正
  - 每段持续时间: 20s
  - 重复3次

试验4: 耦合辨识 (surge + yaw同时)
  - 主推+侧推组合: 主推恒速 + 侧推扫描
  - 目的: 辨识速度对偏航阻尼的影响
  - 主推转速: [500, 1000, 1500] RPM
  - 每档主推下侧推扫描: [±500, ±1000, ±1500] RPM

试验5: 自由衰减 (用于验证)
  - 给初始速度/角速度后所有推进器归零
  - 记录自然衰减过程
  - 从衰减时间常数验证阻尼模型
```

### D.5 分步辨识策略

为避免高维参数空间辨识困难，采用分步解耦策略:

```
步骤1: 纵荡通道 (1-DOF)
  固定: v=w=p=q=r=0 (维持)
  辨识: Xu_dot, 纵荡线性/二次阻尼系数 d1_x, d2_x
  使用: 试验1数据

步骤2: 偏航-横荡通道 (2-DOF)
  固定: u=常数(推进器维持), w=p=q=0
  辨识: Yv_dot, Y_r_dot, Nr_dot, N_v_dot, d1_y, d2_y, d1_r, d2_r, Y_v_r, N_v_r
  使用: 试验2+4数据

步骤3: 俯仰-垂荡通道 (2-DOF)
  固定: u=常数, v=p=r=0
  辨识: Zw_dot, Z_q_dot, Mq_dot, M_w_dot, d1_z, d2_z, d1_q, d2_q, Z_w_q, M_q_w
  使用: 试验3数据

步骤4: 全耦合验证 (6-DOF)
  固定: 所有参数
  验证: 复杂轨迹跟踪试验，对比模型预测 vs 实测
  使用: 试验5数据
```

### D.6 模型验证

#### D.6.1 验证指标

```
1. 预测残差RMS (归一化):
     RMS_i = sqrt(Σ(y_meas_i - y_pred_i)² / N) / max|y_meas_i|

2. 拟合度 (FIT):
     FIT_i = 100 * (1 - ||y_meas - y_pred|| / ||y_meas - mean(y_meas)||)

3. Theil不等系数 (TIC):
     TIC = ||y_meas - y_pred|| / (||y_meas|| + ||y_pred||)

4. 交叉验证:
     使用部分试验数据辨识 → 预测另一部分数据
```

#### D.6.2 验证试验设计

```
验证轨迹1: 直线航行
  主推1500RPM, 其余为0, 持续60s
  对比: 实测u(t) vs 模型预测u(t)

验证轨迹2: 回转
  主推1000RPM + 侧推反向1000RPM, 持续60s
  对比: 实测(x,y)轨迹 vs 模型预测轨迹

验证轨迹3: 正弦舵角
  侧推正弦扫描: frequency sweep 0.1-1.0 Hz
  对比: 频率响应 magnitude/phase

验证轨迹4: Z形机动
  侧推: +1000(10s) → -1000(10s) → +1000(10s) → -1000(10s)
  对比: yaw rate overshoot, settling time
```

### D.7 MATLAB实现框架

```matlab
% 系统辨识主函数框架
function [theta_opt, cov_theta] = sysid_xhy(exp_data, theta_init, params)

    % 1. 参数可辨识性分析
    S = compute_sensitivity(exp_data, theta_init, params);
    [U, S_diag, V] = svd(S'*S);
    fprintf('条件数: %.1f\n', max(S_diag)/min(S_diag));
    fprintf('不可辨识参数: '); disp(find(diag(S_diag) < 1e-3));

    % 2. Gauss-Newton迭代
    theta = theta_init;
    for iter = 1:max_iter
        % 仿真模型
        [y_pred, S] = simulate_with_sensitivity(theta, exp_data, params);
        
        % 残差
        e = exp_data.y - y_pred;
        
        % Gauss-Newton更新
        H = S' * inv(R) * S;      % 近似Hessian
        g = S' * inv(R) * e;       % 梯度
        delta = H \ g;
        
        % 线搜索
        alpha = linesearch(theta, delta, exp_data, params);
        theta = theta + alpha * delta;
        
        % 收敛判断
        if norm(delta) < 1e-6, break; end
    end
    
    % 3. 协方差估计
    cov_theta = inv(H);
    
    % 4. 模型验证
    y_final = simulate_model(theta, exp_data_validation);
    [RMS, FIT, TIC] = validation_metrics(exp_data_validation.y, y_final);
    
end
```

### D.8 替代方案: 子空间辨识 (可选)

如果时域MLE收敛困难，可使用频域或子空间方法:

**子空间辨识** (适用于线性化模型):
```
1. 在平衡点附近线性化AUV动力学
2. 构造Hankel矩阵 → SVD → 提取系统矩阵(A,B,C,D)
3. 从系统矩阵反向计算物理参数
```

此方法已广泛用于船舶/AUV辨识 (参考: Fossen, "Handbook of Marine Craft Hydrodynamics and Motion Control", Ch.13)
