## 二、原始Claim的证据分析

### ✅ 支撑原始Claim的证据

| 证据 | 数据 |
|------|------|
| **失配下退化小于EKF** | PC-RCO +42% vs EKF +77%（圆形0→30%失配） |
| **低噪声下精度优秀** | RMSE=0.064(0%), 0.091(30%), 0.043(直线) |
| **直线不崩塌** | CFD-Luenberger崩塌到2.284，PC-RCO保持0.043 |
| **clamp防止噪声跳变** | 低噪声下dc_ratio仅1.6-1.8x，高噪声下33x |
| **跨平台有效** | REMUS: PC-RCO=0.115 > KIN=0.260 |

### ❌ 不支持原始Claim的证据

| 证据 | 影响 |
|------|------|
| **高噪声(σ=0.10)下RMSE=0.86** | PC-RCO比KIN(0.26)差3.3倍 |
| **GM gate从不关闭** | 三机制中一个完全未激活 |
| **NoPredCorr在高噪声下更好** | prediction-correction不是无条件优势 |

### 🔑 关键区分

**噪声驱动 vs 失配驱动**：E2压力矩阵清楚显示，clamp的dc_max爆炸（29-33x）仅在**高噪声**条件下发生，与失配水平无关。在**低噪声**（真实DVL水平σ=0.02）下，PC-RCO在所有失配水平都保持良好精度。

> **结论: 原始Claim在低/中噪声下成立，方法在高噪声下有已知局限。**

## 三、方法改进方案

### 改进1: 自适应噪声补偿（解决高噪声退化）

**问题**: 高噪声下 e_vel 信噪比恶化 → clamp阻止有效更新 → 无法收敛

**方案**: 自适应增益缩放
```
noise_est = moving_std(e_vel, window=100)  % 实时噪声估计
alpha_noise = exp(-noise_est / noise_ref)   % 噪声自适应因子
max_dc_adaptive = max_dc_base / alpha_noise % 噪声大→放宽限幅
```
但保持硬上限（如max_dc≤0.20）防止完全失去保护。

### 改进2: 混合预测-加速度架构

**问题**: prediction-correction在噪声下收敛慢但瞬态平滑；acceleration residual相反

**方案**: 自适应混合权重
```
w_pred = exp(-noise_est^2 / noise_ref^2)  % 低噪声→prediction为主
c_hat += w_pred * dc_pred + (1-w_pred) * dc_accel
```

### 改进3: 门控机制替换

**问题**: λ_min gate对CFD模型永久开放

**方案**: 用heading变化率作为门控条件
```
gate_closed = |r| < r_threshold  &&  |dpsi_ref| < dpsi_threshold
```
当直航时门关闭→GM衰减生效→估计值缓慢回归先验。

### 改进4: KIN混合先验

**问题**: KIN在噪声下最好(RMSE=0.257)但没有模型信息

**方案**: 用KIN输出作为PC-RCO的GM均值
```
c_mean = alpha_kin * c_KIN + (1-alpha_kin) * [0;0]
```
低激励时c_hat向KIN估计衰减而非向零衰减。

## 四、建议的改进优先级

| 优先级 | 改进 | 预期收益 | 工作量 |
|--------|------|---------|--------|
| **P0** | 改进1: 自适应噪声补偿 | 高噪声下RMSE从0.86 → ~0.4 | 中 |
| **P0** | 改进3: 门控替换 | 让GM衰减可验证 | 小 |
| **P1** | 改进4: KIN混合先验 | 改善长期漂移 | 小 |
| P2 | 改进2: 混合架构 | 噪声鲁棒性进一步提升 | 大 |

## 五、改进后的预期论文Claims

**C1 (主贡献)**: 基于CFD预标定的速度预测-校正架构，在**模型失配**下实现比EKF低35%的退化率（42% vs 77%），同时比运动学方法精度高3倍（0.064 vs 0.192）。

**C2 (支撑)**: 自适应更新率限幅在噪声增大时自动放宽，在保证物理可接受性的前提下改善高噪声收敛性。

**C3 (设计)**: 航向变化率门控替代灵敏度Gramian门控，在长时直航段激活GM衰减，减少估计漂移。
